# Data sources

No data files are committed to this repository. Everything below is downloaded or generated locally
into the git-ignored `data/` folder. Ask before adding or changing any source.

| # | Source | Used for | Link | License / terms | How to obtain |
|---|---|---|---|---|---|
| 1 | Kaggle: *Vehicle Insurance Claim Fraud Detection* (~15k rows, fraud label) | Fraud model training/eval; seed rows for synthetic narratives | https://www.kaggle.com/datasets/shivamb/vehicle-claim-fraud-detection | **CC0-1.0** (public domain), verified from Kaggle metadata on 2026-10-04 and recorded in `data/raw/vehicle_fraud/manifest.json` with the file's sha256. Not redistributed. | `uv run python scripts/download_data.py` (needs `KAGGLE_API_TOKEN` in `.env`) |
| 2 | Kaggle: *Auto Insurance Claims Data* (optional, ~1k rows) | Optional secondary fraud signal / sanity check | https://www.kaggle.com/datasets/buntyshah/auto-insurance-claims-data | Not verified; **not used yet**. Will be checked and added to the download registry only if needed. | n/a |
| 3 | Synthetic claim narratives | End-to-end harness evaluation with ground-truth labels | Generated by `scripts/generate_claims.py` (Step 4) | Ours (MIT). Generated by an LLM conditioned on rows from source 1. | `uv run python scripts/generate_claims.py` |
| 4 | Personal auto policy text | Coverage retrieval and policy graph | `policy/personal_auto_policy.yaml` (Step 3) | Ours (MIT). Written from scratch to follow the general structure of a US personal auto policy; no ISO form text. | In repo |
| 5 | Fraud red-flag rules | Rules engine in the fraud node | `src/autoclaim/lines/auto/` (Step 2) | Ours (MIT). Paraphrased from commonly known industry indicators; no NICB text copied. | In repo |

## Notes
- Kaggle data stays local. Derived artifacts that could reconstruct it (raw row dumps, trained weights) are
  also git-ignored.
- Synthetic narratives are fictional. Any resemblance to real people or claims is coincidental.
